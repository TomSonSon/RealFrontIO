# OpenFront — Real-World Realism Research
## 03 — MILITARY BASES (Worldwide, for starting-structure placement)

**Scope:** Deep, current (2025–2026) catalog of real-world military bases worldwide with decimal lat/long coordinates. These feed the World-map's lat/long→pixel mapping so that defensive posts, ports, missile silos, and factories can be placed at realistic geographic locations for each major power.

**How to read this file**
- All coordinates are **decimal degrees** (WGS84, negative = South / West).
- Coordinates are approximate to the **large installation footprint / center** (runway, port basin, or HQ) — good to ±0.02–0.05° for gameplay placement.
- **Type** uses the OpenFront structure-icons: `DefensivePost` / `Port` / `Silo` / `Factory` / `Air` (use as airfield).
- Sources are cited inline in brackets like `[WIKIPEDIA: X]`, `[Reuters]`, `[US DoD]`, `[FAS]`, `[RFI]`.
- Section 6 (Game Implications) is the practical map-placement summary.

# 1. UNITED STATES — OVERSEAS BASES (the global network)

The U.S. DoD manages or uses **at least 128 overseas bases** in 51+ countries `[CRS R48123]`. Analysts count 750 "base sites"; over 750 sites in 80+ countries historically `[CRS]` `[Al Jazeera, 2021]`. Visual Capitalist counts 128 in 49 countries, led by Japan (14), Philippines (9), South Korea (8) `[Visual Capitalist]`. The game should treat the U.S. as having the deepest global forward-deployment.

# 6. GAME IMPLICATIONS — strategic forward reach & chokepoints

This is the **map-placement** section: which bases each major power should start with, mapped to OpenFront structure types.

## 6.1 Chokepoint bases that matter for naval realism
These control global shipping lanes and are disproportionately valuable as `Port` nodes:
1. **Diego Garcia** (-7.31, 72.41) — dead-center Indian Ocean; U.S./UK `Port`.
2. **Guam (Andersen + Apra Harbor)** (13.58, 144.92 / 13.47, 144.66) — 2nd island chain `Port`/`Air`.
3. **Djibouti cluster** — Camp Lemonnier (US, 11.54, 43.15), PLA base (11.59, 43.06), French base (11.53, 43.14) — guards **Bab el-Mandeb**.
4. **Suez Canal** area (Port Said ~31.25, 32.30; Suez ~29.97, 32.55) — Egypt/Arabian-Med chokepoint.
5. **Strait of Hormuz** — **NSA Bahrain** (26.21, 50.61), **Bandar Abbas** (Iran, 27.18, 56.27), **Al Udeid** (25.12, 51.32), **Al Dhafra** (24.25, 54.55), **Camp Arifjan** (28.88, 48.16).

## 6.3 Recommended placement rules for OpenFront
1. **Map each base to one structure type** matching its dominant role (`Port` for naval bases/SSBN homeports; `Air` treated as a defensive-post variant or airfield factory; `Silo` for ICBM/strategic sites; `DefensivePost` for army garrisons/fortresses; `Factory` for logistics/industrial hubs e.g. shipyards Sevastopol, Sevmash, Dalian, Jiuquan).
2. **Chokepoint weighting:** Place `Port` nodes at Diego Garcia, Guam, Djibouti, Bahrain, Suez, Hormuz (Bandar Abbas), Malacca (Singapore/Andaman) — these should be strategically painful to lose.
3. **Contested/2025-dynamic flags:** Syria (Tartus/Khmeimim), Armenia (Gyumri), Niger (Agadez), and occupied-Ukraine depots should be **variable-alignment** — flippable between major powers to model 2024-25 geopolitical shifts (Assad fall, France African withdrawal, U.S. Niger withdrawal, Armenian drift).
4. **Coordinate precision:** Use the lat/long above as spawn points; the game's lat→pixel mapping should place structure *at or near* the real base. Round celestial-marine distances consistently with the equirectangular map used elsewhere in the project.
